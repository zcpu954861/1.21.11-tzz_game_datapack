# 逃走中数据包 v2.3 详细说明

本数据包为 Minecraft 设计，完整实现了“全员逃走中”小游戏的自动化流程，适合服务器或局域网游玩。

---

## 主要功能一览

### 1. 自动初始化与环境设置
- 自动创建所有所需计分板（scoreboard objectives），包括操作面板、队伍切换、能量、准备、死亡旁观等。
- 自动创建三大队伍：逃走者、猎人、管理员，并设置颜色、名牌、死亡消息等属性。
- 自动设置 gamerule：关闭昼夜更替、天气变化，锁定时间为上午，关闭死亡消息，保持晴天。
- 数据包加载/重载后，自动向全体玩家广播欢迎信息、操作指引、注意事项。

### 2. 操作面板与交互
- 玩家可通过按钮加入逃走者/猎人队伍、离开所有队伍、呼叫管理员。
- 管理员（op）可通过专属面板一键查看队伍成员、清空死亡数据、开启/关闭死亡旁观、直接开始游戏等。
- 所有按钮均有悬浮简介，鼠标悬停可查看功能说明。
- 所有 trigger 功能（如加入队伍、呼叫管理员、显示规则/指引等）始终可用，防止因重载失效。

### 3. 游戏流程自动化
- 游戏开始前猎人自主选择出生点。
- 检查所有玩家是否分组，未分组则广播提醒，全部分组后进入准备界面。
- 玩家点击“我准备好了”按钮，op 可检测全员准备状态，全部准备后可正式开始游戏。
- 游戏开始前自动进行10秒倒计时，每秒广播提示与音效。
- 游戏正式启动后，能量系统、计分板、猎人击杀数等全部自动重置并激活。

### 4. 能量与计分系统
- 每秒为所有存活逃走者自动增加能量（tzz_run_energy），侧边栏实时显示。
- 猎人每击杀一名逃走者，计分板自动统计，开局时重置。
- 自动统计当前存活玩家数量并广播。

### 5. 死亡与旁观机制
- 开启死亡旁观后，非 op 玩家死亡会自动切换为旁观者模式并打上 death 标签，同时广播被捕信息。
- 每有玩家死亡，自动统计剩余逃走者数量并广播。
- 管理员可一键清空所有玩家的死亡数据。

### 6. 定时与广播
- 每分钟自动广播一次，提醒玩家可跳转操作面板。
- 数据包加载或重载后1秒自动广播欢迎与指引信息。

### 7. 游戏规则与指引
- 玩家可随时查看游戏规则（如禁止上房顶、爬树、下水、跑酷，严禁游戏中更改队伍等）。
- 玩家可随时查看游戏玩法指引（如 F3 查看方向、合作任务、能量获取等）。

### 8. 管理员权限与进阶功能
- 只有获得 op 标签的玩家可见并操作管理员面板，权限通过 `/tag @s add op` 获得。
- 通过 advancement 文件实现游戏内成就与进度提示。
- 如 trigger 功能失效，玩家可通过面板一键恢复所有功能可用性。

### 9. 兼容性与异常处理
- 数据包会提示无法自动加载某些小地图状态效果，需玩家手动操作。
- 如遇异常可用 `/reload` 重载数据包，所有计分板与功能会自动恢复。

---

## 快捷操作与注意事项

1. 所有按钮均有悬浮简介，不清楚功能时请将鼠标悬停查看。
2. 游戏开始后仍可切换队伍，但此操作可能引发未知 BUG，建议勿在游戏中更换队伍。
3. 所有计分板项目会自动加载，无需手动创建。
4. 如遇任何问题可随时 `/reload` 重载数据包。
5. 管理员功能需先通过 `/tag @s add op` 获得权限。

---

## 目录结构简述

- `data/tzz_game/function/`：核心功能脚本（能量、开局、倒计时等）
- `data/tzz_global_function/function/`：全局功能（如死亡切旁观、玩家效果）
- `data/tzz_initialize/function/`：初始化相关（计分板、队伍、gamerule 等）
- `data/tzz_main_user_operation_panel/function/`：主用户操作面板与引导
- `data/tzz_scheduled_tasks/function/`：定时广播等任务
- `data/tzz_game/advancement/`：成就与进度
